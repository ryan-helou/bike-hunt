# Bike Hunt

A personal tracker for finding a good deal on a used triathlon bike.

The owner is shopping for a second-hand triathlon (time-trial) bike for an upcoming race and only wants to hear about bargains. An AI assistant searches used-bike listings a few times a day, judges each one (fit, condition, fair price, total cost), and records what it finds. This small web app is where those results are shown. It was built for one buyer, not as a general tool.

## What you can do with it

- See every bike being tracked, grouped by where it stands (worth asking about, waiting on a reply, passed on, sold, and so on).
- Check each listing's asking price, estimated fair value, target price, and the margin between them.
- Follow price drops over time on a listing.
- Read the notes on each bike, such as size, model year and anything spotted in the photos.
- Review drafted messages to sellers. Nothing is sent automatically; each message needs the owner's approval first.
- Turn on phone notifications so a good find shows up right away. The app can be added to a phone's home screen like a regular app.

A banner warns when no search has run for a while (for example, if the computer running the searches was asleep).
